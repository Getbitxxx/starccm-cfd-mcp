# 源码分发与验证说明

本次于 2026-11-14 从本地 STAR-CCM+ MCP 提取源码，使用新的 Git 历史发布，避免旧提交带入私有记录或已删除文件。源提交及逐文件 SHA-256 见 `source-snapshot.json`。源码中的个人主目录与实际内网主机被替换为占位值；任何历史审批均不适用于脱敏后的新字节。

分发包含控制器、宏、工作器、工作流、操作目录、Skills、知识索引、测试与小型 CaseSpec。未分发真实连接配置、SSH 密钥、运行时快照、独立批准、仿真/CAD/网格/场数据和研究证据。文档和目录中保留的历史证据引用只用于定位，不构成可用证书。部分脚本依赖专用外部工具或原项目目录，安装 MCP 核心依赖并不会自动配置这些研究工具。

`tools/check_source.py` 检查敏感文件、常见凭据格式、单文件大小、源码快照哈希和 Windows 运行时声明文件完整性。`tools/check_offline.py` 仅加载明确列出的可移植测试；完整研究测试仍位于 `tests/`，不以跳过或修改历史断言制造全绿。

本次工作对流程通用性、场景覆盖、单样本工程推进的增量均为零；新增的是可复核的源码分发及离线检查入口。没有运行 STAR、部署工作器、重新批准历史字节或改变研究质量标签。历史 P/E 数值未随本次分发重新认证。
