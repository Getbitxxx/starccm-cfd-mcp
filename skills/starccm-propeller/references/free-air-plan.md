完成开放空气模板的必要阶段：

1. **工况合同**：记录桨直径、叶片数、轴心/转轴、来流速度与方向、转速、气体状态、稳态 MRF 或瞬态运动、推力/扭矩正方向。本算例的所选方案是完整 360° 三叶几何，不使用周期扇区边界；整机无人机另用全域模板。
2. **计算域与边界**：`external-domain-2502/build` 已能在独立副本中按 CaseSpec 明确给出的 `domain.outer_bounds_m` 创建盒形外域并扣除桨部件；该步骤已通过几何级 API 试验，尚未创建新流体区域，也没有确定工程边界距离。在 CAD/STAR 几何副本上建立足够远的上游、下游和径向外边界，明确入口、出口和侧界的边界类型。不能只把现有近距离 `FLUID/WALL` 改名或改成滑移面就声称开放空气。至少用两档更远的域尺寸比较载荷与流场，直到对目标精度的影响可接受。
3. **网格与模型**：审查 CAD 封闭性、周期配对、桨域接口、叶尖/尾迹局部加密、棱柱层与 y+；生成至少两档网格，记录单元数/质量/载荷变化。湍流模型与近壁处理要和 y+ 一起选，不能从旧网格的监控值推断新网格合格。
4. **求解与验收**：保存每档算例的输入哈希、宏版本、STAR 版本、参数、网格和日志；监控推力、扭矩、功率、效率、质量守恒及逐方程残差。检查窗口稳定性、域和网格敏感性，再依据实验或可信参考数据做物理验证。`SUCCEEDED` 只表示程序完成。
